# VectorHub OSS 产品需求文档（PRD）

**版本**：v0.2  
**状态**：已确认，可进入开发  
**更新日期**：2026-10-08  
**项目名称**：VectorHub OSS / VectorHub Lite  
**一句话定位**：一个无登录、开源、本地优先、首页即编辑器的在线 SVG 编辑器，专注路径编辑与代码导出。  
**核心原则**：SVG 优先、本地优先、开源优先、代码优先、无登录、Editor-first。

---

## 0. 文档说明

### 0.1 文档目的

本文档用于明确 VectorHub OSS v0.1 的产品范围、功能需求、非功能需求、技术方向、优先级、开源治理和验收标准，作为产品、设计、研发、测试和社区协作的共同依据。

### 0.2 版本变更摘要

v0.2 相比 v1.1 的核心变更：

1. 从 SaaS 协作平台转向 **无登录、开源、本地优先的 OSS 编辑器**。
2. 采用 **首页即编辑器（Editor-first）** 架构，`/` 直接进入编辑器。
3. 移除登录、云端项目、团队协作、支付等 P0 内容。
4. 新增本地项目抽屉、命令面板、URL 分享、PWA、快速开始浮层。
5. P0 范围收敛为“画布编辑 → SVG 结构树 → 代码面板 → 导出/复制代码 → 本地保存/URL 分享”。
6. SVG 优先原则补充可衡量验收标准，并新增“体积与性能优先”。
7. 商业模式改为 Open Core：核心开源，云服务后续闭源收费。

### 0.3 优先级定义

| 优先级 | 含义 |
|---|---|
| P0 | v0.1 必须上线，缺失则产品无法成立 |
| P1 | v0.2–v0.3 迭代，重要竞争力 |
| P2 | v1.0+ 平台化与商业化 |
| P3 | 探索性功能，暂不进入排期 |

### 0.4 术语

| 术语 | 说明 |
|---|---|
| SVG | 可缩放矢量图形，基于 XML 的二维矢量格式 |
| 画布 | 用户进行图形编辑的核心区域 |
| 节点 | SVG 路径中的控制点 |
| 本地优先 | 数据默认保存在浏览器 IndexedDB，不上传服务器 |
| 命令面板 | `Cmd/Ctrl + K` 打开的统一操作入口 |
| 项目抽屉 | 编辑器内打开本地项目列表的面板 |
| 分享链接 | 文档压缩编码到 URL hash，不经服务器 |
| PWA | 渐进式 Web 应用，支持离线与安装 |
| Open Core | 核心开源，云服务/企业版闭源收费 |

## 1. 背景与决策

### 1.1 背景

原 VectorHub 定位为面向设计师、开发者和团队的在线 SVG 设计协作平台。经过评审，决定调整冷启动策略：

- 先不做登录、云端项目、团队协作和 SaaS 订阅。
- 先做一个 **无登录、开源、本地优先** 的在线 SVG 编辑器。
- 用开发者口碑、GitHub 社区和工具属性获客。
- 验证核心闭环：**画布编辑 → SVG 结构树 → 代码面板 → 导出/复制代码 → 本地保存/URL 分享**。

### 1.2 决策

**v0.1 采用纯前端架构，无后端、无账户体系。**  
用户打开网页即可使用，数据默认保存在浏览器本地。项目通过文件导入导出或 URL hash 分享，不上传服务器。

**首页即编辑器。** 根路径 `/` 直接进入编辑器，不再有独立首页或工作台。本地项目列表、模板、导入、分享、设置都以抽屉、浮层或命令面板的形式出现在编辑器内。

### 1.3 参考模式

- Excalidraw：无登录、本地优先、开源、URL 分享。
- tldraw：开源编辑器 + 商业云服务。
- SVGPath Pro：路径编辑与代码生成。
- Penpot：开源设计协作，但偏重团队与自托管。

## 2. 产品目标

### 2.1 核心目标

- 提供一个打开即用的在线 SVG 编辑器。
- 以路径、节点、SVG 结构树和代码面板为核心。
- 支持本地自动保存、文件导入导出和 URL 分享。
- 支持导出生产级 SVG、React、Vue、HTML/CSS 代码。
- 以开源方式建立开发者社区和插件生态。
- 首页即编辑器，首次激活路径最短。

### 2.2 业务目标

- 通过开源获客，建立品牌和社区。
- 验证 SVG 优先工作流是否被设计师和开发者接受。
- 为后续云同步、实时协作、团队版和企业版打基础。
- 后续采用 Open Core 模式：核心开源，云服务闭源收费。

### 2.3 用户目标

- 开发者无需注册即可快速编辑 SVG 并复制代码。
- 设计师可在线完成图标、路径、简单插画设计。
- 团队可本地使用，数据不出浏览器。
- 用户可离线使用，可安装为 PWA。

### 2.4 非目标

v0.1 不做：

- 注册、登录、账户体系。
- 云端项目、跨设备同步。
- 实时协作、评论、版本历史。
- 团队、权限、SSO、审计。
- 支付、订阅、发票。
- 模板市场、品牌套件。
- React Native、Flutter、Svelte、NPM、CDN 导出。
- 复杂布尔、蒙版、滤镜、SVG 动画。

## 4. 产品原则

### 4.1 SVG 优先原则

1. **标准优先**：内部对象映射标准 SVG 元素，导出必须通过 SVG 1.1 校验。
2. **代码优先**：默认交付生产级代码，代码面板默认可见，默认 `currentColor`、`viewBox`、基础 aria。
3. **路径与节点优先**：首屏工具栏以钢笔、节点、布尔、优化为核心；选中路径显示节点数、路径长度、可优化空间。
4. **双向同步**：代码与画布修改延迟 <100ms，冲突以画布为准。
5. **资产化协作**：v0.1 预留节点级评论和 SVG diff 数据结构，v0.2+ 实现。
6. **效率标尺**：需求评审必须回答是否减少设计到代码步骤；目标手动修改时间减少 ≥50%。
7. **体积与性能优先**：实时显示节点数与体积，一键优化，典型图标体积优化 ≥20%。

### 4.2 本地优先原则

- 默认数据保存在浏览器 IndexedDB。
- 不强制上传、不强制登录。
- 支持导出项目文件和 SVG 文件。
- 支持离线使用和 PWA 安装。
- URL 分享通过 hash 压缩，不经过服务器。

### 4.3 开源优先原则

- 核心编辑器开源，建议 MIT 或 Apache-2.0。
- 插件 API 开放，鼓励社区扩展。
- 文档、示例、路线图公开。
- 云服务、协作、企业版后续闭源商业化。

### 4.4 无登录原则

- 打开即用，无注册、无登录、无弹窗。
- 不做用户系统、不做云端账户。
- 项目归属通过本地存储和文件管理实现。
- 分享通过 URL 或文件完成。

### 4.5 Editor-first 原则

- 根路径 `/` 即编辑器。
- 不设独立首页、工作台或项目列表页。
- 项目、模板、设置、分享以编辑器内面板形式出现。
- 所有高频操作可通过命令面板完成。
- 首次访问无阻塞弹窗，快速开始浮层可一键关闭。

## 5. 信息架构与路由

### 5.1 路由设计

```text
/                         编辑器，打开最近项目或新建草稿
/?project=<id>            打开指定本地项目
/#share=<compressed>      打开只读分享文档
/?panel=projects          打开项目抽屉
/?panel=templates         打开模板面板
/?panel=settings          打开设置
/about                    静态介绍页，可选
/docs                     静态文档页，可选
```

**原则**：应用入口永远是编辑器，其他功能不抢占首屏。

### 5.2 编辑器布局

```text
┌──────────────────────────────────────────────────────────────┐
│ Logo  项目名▾  已保存   │ 撤销 重做 │ 工具 │ 导出 分享 命令 GitHub │
├──────────┬──────────────────────────────────────┬────────────┤
│ 工具     │                                      │ 属性       │
│ 图层     │              画布                    │ SVG 结构树 │
│ 项目     │                                      │ 代码面板   │
│ 模板     │                                      │            │
├──────────┴──────────────────────────────────────┴────────────┤
│ 缩放 100%  坐标 x,y  节点数 128  预估 4.2KB  状态：本地草稿    │
└──────────────────────────────────────────────────────────────┘
```

### 5.3 顶部栏

- 左侧：Logo、项目名（可点击重命名）、保存状态。
- 中间：撤销、重做、常用工具。
- 右侧：导出、分享、命令面板、GitHub。
- 保存状态：`保存中…` / `已保存` / `离线草稿` / `保存失败`。

### 5.4 左侧栏

- 工具：选择、钢笔、节点、形状、文本。
- 图层：图层树、分组、锁定、隐藏。
- 项目：打开项目抽屉。
- 模板：打开模板面板。

### 5.5 右侧栏

- 属性：填充、描边、渐变、尺寸、位置。
- SVG 结构树：查看、选中、编辑标签和属性。
- 代码面板：SVG、React、Vue、HTML/CSS，默认可见，可折叠。

### 5.6 底部状态栏

- 缩放、坐标、节点数、预估导出体积、保存状态。
- 点击节点数或体积可打开优化建议，v0.2 提供一键优化。

## 6. 核心用户流程

### 6.1 首次访问

1. 打开 `/`。
2. 立即创建“未命名项目”草稿。
3. 画布直接可用。
4. 画布中央显示快速开始浮层：

```text
┌─────────────────────────────┐
│  开始你的第一个 SVG          │
│                             │
│  [新建空白]  [导入 SVG]      │
│  [粘贴 SVG]  [选择模板]      │
│  [打开本地项目]              │
│                             │
│  按 Esc 或点击画布关闭       │
└─────────────────────────────┘
```

5. 不弹注册、不弹登录、不弹引导页。
6. 用户点击任意选项或直接开始绘制，浮层消失。
7. 草稿自动保存到 IndexedDB。

**成功标准**：新用户 5 分钟内完成创建并导出。

### 6.2 开发者编辑 SVG 并复制 React 代码

1. 导入或粘贴 SVG。
2. 选中路径，查看节点数和 `d` 属性。
3. 在代码面板选择 React + TypeScript。
4. 配置组件名、尺寸、`currentColor`、`aria-label`。
5. 复制代码。
6. 可选：导出 SVG 文件或分享 URL。

### 6.3 URL 分享

1. 点击“分享”。
2. 系统将文档压缩编码到 URL hash。
3. 复制链接。
4. 对方打开链接，直接加载文档。
5. 数据不经过服务器，只读打开。
6. 顶部提示条：`你正在查看分享文档 [复制到我的项目] [下载 SVG]`。
7. 点击“复制到我的项目”后生成新本地项目，可编辑。

### 6.4 本地项目切换

1. 点击顶部项目名下拉，或左侧“项目”图标，或 `Cmd/Ctrl + O`。
2. 打开项目抽屉。
3. 搜索、选择、重命名、复制、删除、导入、导出项目。
4. 切换时当前项目自动保存。

### 6.5 离线使用

1. 首次访问后 Service Worker 缓存资源。
2. 断网后仍可打开编辑器。
3. 本地保存和导出继续可用。
4. 联网后无同步需求，因为数据默认本地。

| 代码面板同步 | <100ms |

| 导出 PNG 2x | <3s |
| URL 压缩 | <200ms |

### 8.2 可用性

- 无登录，打开即用。
- 自动保存失败时本地缓存。
- 支持断网查看和编辑草稿。
- 关键操作有撤销和确认。

### 8.3 安全与隐私

- 数据默认保存在浏览器本地。
- 无后端上传，无账户，无追踪。
- URL 分享数据在 hash 中，不经过服务器。
- 插件系统后续需要权限声明和沙箱。

### 8.4 兼容性

- Chrome、Edge、Safari、Firefox 最新两个版本。
- 移动端支持查看、简单编辑和导出，完整编辑优先桌面。
- 导出 SVG 兼容主流浏览器和常见设计工具。

### 8.5 可访问性

- 编辑器关键操作支持键盘快捷键。
- 导出代码支持 aria-label、role、title、desc。
- 界面颜色对比度符合 WCAG 2.1 AA 基础要求。

## 9. 技术方案

### 9.1 前端

- React 18 + TypeScript + Vite。
- 渲染：SVG DOM 为主，Canvas 辅助高性能预览和选区。
- 状态：Zustand。
- 代码编辑器：Monaco Editor。
- UI：Radix UI + Tailwind CSS。
- 本地存储：IndexedDB（idb）。
- URL 分享：lz-string。
- 文件系统：File System Access API（可用时）。
- 导出：Web Worker 处理 SVG 优化和 PNG 生成。
- PWA：Vite PWA 插件。

### 9.2 后端

v0.1 **无后端**。  
部署为纯静态站点，支持 GitHub Pages、Cloudflare Pages、Vercel、Netlify。

### 9.3 代码生成

- 自定义 AST 中间层。
- 设计对象 → 中间 AST → 目标代码。
- 支持 SVG、React、Vue、HTML/CSS。
- 支持组件名、props、尺寸、`currentColor`、基础 aria。
- SVG diff 数据结构预留，v0.1 不实现 UI。

## 17. 风险与应对

| 风险 | 影响 | 应对 |
|---|---|---|
| 无登录导致用户沉淀弱 | 留存低 | URL 分享、本地项目、PWA、后续可选云同步 |
| URL 长度限制 | 分享失败 | 压缩、提示改用文件分享 |
| 大文件性能问题 | 卡顿 | 虚拟化、分片、Canvas 辅助 |
| 浏览器兼容差异 | 导出异常 | 兼容性检查、标准属性优先 |
| 开源被白嫖 | 商业化难 | Open Core，云服务闭源 |
| 插件安全风险 | 数据泄露 | 权限声明、沙箱、审核 |
| 社区冷启动 | 无人使用 | 产品发布、文档、示例、插件激励 |
| 竞品强大 | 获客难 | 聚焦 SVG 优先、本地优先、代码导出 |
| 代码导出质量不稳定 | 用户流失 | AST 中间层、测试用例、质量评分 |
| 首页即编辑器增加首屏压力 | 加载慢 | 代码分割、懒加载、骨架屏、PWA 缓存 |
